# Mídias do Questudo

Este repositório hospeda, em HTTPS, as mídias autorais usadas nas questões do
Questudo: gráficos, tabelas, diagramas, mapas esquemáticos e ilustrações
educacionais.

## Uso pelo Quesmax

Cada item publicado deve constar em `manifest.json` com identificador, tipo,
URL HTTPS, texto alternativo, fonte e licença. O Quesmax só pode referenciar
itens presentes nesse catálogo e deve enviar esses mesmos metadados no payload
da questão.

## Direitos e atribuição

Salvo indicação expressa em contrário no item, as mídias são **Elaboração
própria — Questudo** e têm licença **Uso autorizado no Questudo**. A exposição
pública deste repositório serve exclusivamente para entrega técnica dos
arquivos por HTTPS; ela não transfere direitos de reutilização, redistribuição
ou venda.

Não inclua material de terceiros sem URL de origem, autor e licença compatível.
